# Compilación

Visual Studio 2022 Build Tools, x64.

build_wake_engine.bat genera dist\JarvisWake.exe.
No se compiló ni se midió RAM en el entorno de desarrollo.
El proceso no abre el micrófono.
Activación: Ctrl+Alt+J.
Inicio de Windows: dist\JarvisWake.exe --install-startup
Quitar: dist\JarvisWake.exe --remove-startup
JARVIS_ASSISTANT apunta al asistente.
